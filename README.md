# 𝑀𝒜𝒩𝒲 تيك توك

تطبيق Android لإدارة قائمة حسابات TikTok وفتح رابط فيديو داخل التطبيق الرسمي.

## المميزات
- حفظ أسماء الحسابات محليًا على الجهاز.
- تحديد الحسابات التي تريد إدارتها.
- فتح رابط فيديو TikTok في التطبيق الرسمي.
- لا يطلب كلمات المرور أو يخزن بيانات تسجيل الدخول.

## بناء APK
من GitHub افتح **Actions** ثم شغّل **Build MANW TikTok APK**، أو ادفع تحديثًا إلى فرع `main`.
بعد نجاح البناء نزّل الملف من **Artifacts** باسم `MANW-TikTok-debug`.

## حدود التكامل
هذه النسخة لا تنفّذ إعجابات أو متابعات أو تعليقات جماعية آلية. التفاعلات تتم يدويًا داخل TikTok.
