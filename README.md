# MANW App Hider

تطبيق Android عادي (ليس مشغّلًا رئيسيًا) لإدارة إخفاء التطبيقات المختارة باستخدام Shizuku.

## المميزات
- يطلب كلمة مرور عند فتح التطبيق: `manw1231$$`.
- يعرض التطبيقات القابلة للتشغيل ويتيح إخفاءها وإظهارها من داخل MANW.
- يستخدم Shizuku بموافقة المستخدم، ولا يحاول تجاوز شاشة الموافقة.
- لا يضيف MANW نفسه كمشغّل HOME؛ يظل أيقونة عادية في المشغّل.

## الإعداد
1. ثبّت وشغّل تطبيق Shizuku. على الأجهزة غير المروّتة، ابدأ الخدمة من خلال Wireless debugging (أندرويد 11 أو أحدث) أو عبر ADB.
2. افتح MANW وأدخل كلمة المرور.
3. اضغط «الاتصال بـ Shizuku / طلب الإذن» ووافق على طلب MANW داخل Shizuku.
4. اختر التطبيق واضغط «إخفاء». لإعادته افتح تبويب «المخفية» واضغط «إظهار».

## تنبيه مهم
الإخفاء يُنفذ باستخدام `pm disable-user` عبر Shizuku، وهذا **يعطّل التطبيق المحدد على المستخدم الحالي** وليس مجرد إزالة أيقونته. التطبيق المعطّل لا يعمل في الخلفية وقد تتوقف إشعاراته وخدماته حتى تعيد تفعيله. بعض تطبيقات النظام أو التطبيقات المحمية قد يرفض أندرويد تعطيلها. لا تخفِ تطبيقات النظام المهمة أو تطبيقات الاتصال/الإعدادات/المشغّل. احتفظ بطريقة للوصول إلى Shizuku وMANW لإعادة تفعيل التطبيقات.

كلمة المرور مضمّنة داخل التطبيق كحاجز محلي بسيط وليست حماية تشفيرية؛ يمكن لمستخدم متقدم استخراجها من APK.
